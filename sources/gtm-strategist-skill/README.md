# gtm-strategist

A Claude Code skill packaging go-to-market strategy frameworks, prompts, and playbooks as reusable reference material — for ICP/ECP definition, positioning & messaging, launch planning, pricing, AEO/SEO for AI visibility, GTM tool stack decisions, and GTM context/repo architecture for Claude Code.

Content curated from Maja Voje / GTM Strategist's public LinkedIn posts and infographics. This is a knowledge-base skill, not original research — see individual reference files for framework attribution.

## Install

Copy this folder into `~/.claude/skills/gtm-strategist/` to make it available across your Claude Code sessions.

## Structure

- `SKILL.md` — entry point, triggers automatically on GTM-related requests, with a quick-triage table pointing to the right reference file
- `references/frameworks.md` — GTM Iceberg, ECP/ICP, PMF Cycle, Beachhead Strategy, The Chasm, DMU pyramid, Price Friction, etc.
- `references/prompts.md` — 15 GTM prompts for Claude, organized cold start → heating up → on fire
- `references/aeo-seo.md` — Answer Engine Optimization: 6-pillar framework + 6-step playbook
- `references/repo-architecture.md` — CLAUDE.md + context/ + skills/ + workflows/ pattern for a durable GTM system
- `references/tool-stack.md` — tool comparisons (Attio vs HubSpot, Swan AI vs Claude Code, Clay playbooks, MCP map)
- `references/claude-workflows.md` — Claude Code commands, adoption data, international launch checklist
- `references/growth-loops.md` — growth loop archetypes + 2026 acquisition channel shifts
- `references/linkedin-playbook.md` — LinkedIn as a GTM channel: profile optimization, 5 modes, 7 playbooks
