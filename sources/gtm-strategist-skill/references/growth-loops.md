# Growth Loops

Source: curated from Maja Voje / GTM Strategist LinkedIn content. Use when a user asks how to build compounding/self-reinforcing growth instead of one-off campaigns — growth loops are the mechanism that makes "growth ↑, CAC ↓" happen over time instead of every acquisition costing the same as the last.

A growth loop is a closed cycle where the output of one user's action becomes the input that acquires the next user — unlike a funnel (linear, resets every time), a loop compounds.

## 8 Loop Archetypes (with real company examples)

- **Referral Loop** (bolt.new, powered by Cello): user signs up → likes/uses product → tells others → new user signs up.
- **Partners & Affiliates Loop** (Shopify Partner, powered by Cello): partner recruited → promotes to their audience/clients → co-marketing/enablement/incentives → new user signs up.
- **Company Generated Content Loop** (HubSpot): company creates content → multi-channel repurposing → audience subscribes to owned channel → subscribers share with their network.
- **UGC Loop** (Tally): user uses product and shares content with peers → featured content promotion → new users see content and sign up → incentivize further content creation.
- **Integration Growth Loop** (Zapier): new user signs up → product embeds in workflow (becomes sticky) → partner co-marketing incentives → partner promotes integration to their audience → user connects integration to existing tools.
- **Casual Contact Loop** (Calendly): new user signs up → uses product to create an asset (survey, presentation, scheduling link) → shares asset with non-users → others discover product via "powered by" branding.
- **Retention Loop** (Slack): new user signs up → experiences value consistently → satisfaction grows (NPS 9-10) → advocates, referrals, community → proactive health scoring keeps the loop alive.
- **Onboarding Loop** (Canva): new user joins → hits the core action / "aha moment" → network effects/social reward → invited users get a notification & signup offer/multiplier → "share to unlock" value multiplier.

## Growth OS — connecting the loops

A meta-architecture linking loops together rather than running them in isolation: a **Signal Layer** and a **Reinvestment Layer** wrap around a **Core Growth Engine** that links Retention, Organic Viral, Onboarding, Integration Growth, and Casual Contact loops together. The idea: output from one loop (e.g. retained users) becomes reinvestment fuel for another (e.g. referral). When a user has one loop working, the next question is which adjacent loop it should feed.

## 5 More Loop Types (with different company examples — same underlying patterns, useful as an alternate set of references)

- **Viral Loop** (Spotify): new user signs up → shares data/playlist → feeds playlist data back into the product → data is summarized/surfaced to others.
- **Referral Loop** (Dropbox): new sign-up → shares with a friend → friend is asked to share for a reward.
- **Usage-Based Loop** (Loom): new sign-up → records a video → shares the video (the artifact itself is the acquisition vehicle).
- **User Generated Loop** (Quora): new sign-up → user creates content → content gets indexed by search → new users find the content.
- **Collaboration Loop** (Figma): new sign-up → creates a design → invites team members → team members join.

## How to apply this with a user

1. Ask what artifact or action their product naturally produces that a *non-user* could see or benefit from (a shared doc, a scheduling link, a recorded video, a referral reward) — that's the raw material for a loop.
2. Match it to the closest archetype above rather than inventing a new mechanism from scratch.
3. Check whether the loop is actually closed (does the new user's action feed back into acquiring the next one?) — a referral program without an obvious cycle trigger is just a discount, not a loop.
4. Don't recommend stacking many loops at once for an early-stage product — one working loop beats five half-built ones.

## Related: New B2B Acquisition Channels (2026 shift)

From "2026 State of GTM Engineering" research (Poyar & Voje, 183 companies surveyed). Context stats behind the shift: CAC payback for public SaaS ≈ 4.7 years; sites ranking #1 on Google have lost ~79% of search traffic to AI summaries; cold call connection rates dropped from 54% to 20% in a year; reply rates down 32% on email and 45% on LinkedIn. Five channels top GTM teams are shifting budget toward:

| Channel | Why it's rising | Leading vendors |
|---|---|---|
| GEO (Generative Engine Optimization) | Be the answer AI gives, not the link nobody clicks | Profound, Peec AI, Maintouch |
| Influencers | Borrowed trust beats bought reach | Passionfroot |
| Affiliates | Partners sell, you pay on results — CAC stays in your control | Cello |
| User referrals | The one channel where CAC falls and LTV climbs | Cello |
| Integrations/MCP | Distribution inside AI apps buyers already use | Anthropic, Supabase, Lovable |

GEO leads on revenue impact; user referrals lead on efficiency (low setup/maintain cost, low CAC). Affiliates and referrals share a key trait: you only pay when revenue shows up — worth flagging to a user weighing paid channels against these lower-risk alternatives.
